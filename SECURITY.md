# Security policy

OutcomeMesh Core is pre-alpha. Current releases are for development networks and
are not ready to secure assets of real value. Supported builds use Go 1.27.3.
Go 1.26.7 and older toolchains are no longer supported by the project.

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/OutcomeMesh/outcomemesh/security/advisories/new).
Include the affected commit or release, reproduction steps, expected behavior
and likely impact. Keep credentials, private keys and private operator data out
of reports. Do not publish exploit details in public issues before coordination.

The project does not currently offer a bounty or a guaranteed response deadline.
Do not probe other people's nodes or funds without their permission.

The [security model](docs/SECURITY.md) describes component trust boundaries and
outstanding production requirements.

# OutcomeMesh Core v0.1.0-alpha.2

This pre-alpha version is intended for development networks. It does not authorize
mainnet activation or operation with assets of real value.

New scheduled Prune tasks can require an independent witness claim before
storage deletion. Policy and witness scope are fixed before admission. The
storage target consumes a live session permit once and retains a signed result.
Interrupted or copied executors cannot recreate that session from disk; unresolved
outcomes keep their obligations. The CLI now covers policy and scope publication,
network quorum collection and completion through the original owners.

The new path uses request v3, scheduled plan/inventory v1 and executor start v2.
Existing formats and chain storage journals remain unchanged. Existing admissions
cannot be upgraded by replacing their policy or request. See
[the Prune procedure](https://github.com/OutcomeMesh/outcomemesh/blob/v0.1.0-alpha.2/docs/PRUNE_FENCE.md)
for setup, recovery and trust assumptions.

Official archives use Go 1.27.3 and cover Linux and macOS on amd64 and arm64.
Release creation requires annotated tags, current complete CI and CodeQL results,
and identical archives from two builds with separate caches. Archives include
source and dependency metadata, license notices, checksums and GitHub provenance.

Independent operator deployment, settlement without a retained signed result,
external review and public-network stability gates remain open.

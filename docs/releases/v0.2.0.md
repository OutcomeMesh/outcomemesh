# OutcomeMesh Core v0.2.0

This development release adds Windows distributions and establishes a common
version policy for source, binaries and release tags. It remains pre-alpha and
is not approved for networks holding assets of real value.

## Changes

- Windows x64 and ARM64 ZIP archives join the Linux and macOS archives. Each
  includes `omd.exe`, build information and dependency licenses.
- The Windows wallet creates files with a protected ACL for the current user
  and SYSTEM. Reads reject public permissions, another owner, links, device
  paths, alternate streams and oversized files. Encrypted key encoding is
  unchanged.
- The guard HTTP client is portable. Custody guard, gateway and profile-5 owner
  services retain their Unix isolation backend. Their Windows entrypoints
  reject execution before reading keys or writing state.
- `VERSION` is the release source of truth. Official packaging requires its
  matching tag and committed notes. Feature releases advance the minor version;
  corrections advance the patch version. Existing alpha tags remain intact.
- Release builds include all six archives in reproducibility comparison,
  checksums and GitHub provenance. Native Windows checks are required alongside
  the existing Linux and macOS gates.

## Compatibility

No consensus rule, chain format, activation height or obligation is changed.
The supported compiler remains Go 1.27.3. Windows ARM64 binaries are
cross-compiled; native ARM64 runtime qualification remains open. See
[Windows operation](../WINDOWS.md) for supported commands and storage limits.

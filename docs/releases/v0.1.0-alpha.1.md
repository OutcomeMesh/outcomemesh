# OutcomeMesh Core v0.1.0-alpha.1

This is the first packaged pre-alpha release of OutcomeMesh Core. It is intended
for development networks and operator evaluation, not for a mainnet holding real
value.

## Toolchain and downloads

- Go 1.26.7 is no longer supported by OutcomeMesh Core.
- The minimum supported version and official binary toolchain are Go 1.27.3.
- Archives are available for Linux and macOS on amd64 and arm64.
- Each archive includes `omd`, build information and dependency license notices.
  Run `omd version --json` to see its version, commit and Go toolchain.
- `SHA256SUMS` covers the archives, build information and source manifest.

## Included in this release

The standalone development ledger includes resource ownership, constrained
transfers, proof-of-work mining, persistent storage and QUIC peer connections.
Experimental custody commands include protected profile-5 execution, independent
choice seals and permanent external revocation of service and witness keys.

Revocation prevents new guard confirmations. It does not erase previously signed
proofs, undo completed work or release unresolved obligations. The independent
guard still requires protected operation outside participant backups.

There is no mainnet activation in this release. WorkGraph and the operator
subsystems remain explicitly experimental.
